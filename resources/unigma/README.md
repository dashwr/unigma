# unigma — identidade de distribuição

este diretório contém somente identidade própria do produto. nenhum ativo
identificável de Code - OSS, Visual Studio Code ou OpenCode deve ser colocado
aqui.

## direção visual

- lettering geométrico/block-like como referência de princípio, não cópia;
- marca construída com blocos verticais próprios;
- paleta roxo/magenta/violeta, com roxo como cor predominante;
- sheen metálico controlado como acabamento;
- temas sobre fundos branco, lilás, preto e roxo-escuro;
- tagline: `There's no secret.`;
- interface padrão em inglês; pacote `pt-BR` permanece responsabilidade da
  localização do workbench.

A imagem fornecida pelo responsável é apenas referência visual, não ativo
distribuível.

`Cinderblock` permanece candidata não incorporada nesta etapa. Sua
disponibilidade, licença, pesos e direitos de uso ainda precisam ser verificados
antes de qualquer incorporação ou distribuição.
